# ヒーローエリア制作プロンプト

イメージを伝え、Codexで異なる3案を制作・比較してから、採用案のファイルと設計意図を受け取るためのプロンプトです。LP・ホームページ・自作ゲームの入口に使えます。

## 使い方
1. [PROMPT.md](PROMPT.md)の全文をコピーし、Codexアプリの制作したいタスクに貼ります。参照可能なファイルとして渡して「この内容で進めて」と依頼しても構いません。
2. 冒頭の「今回つくるもの」を、分かる範囲で書きます。専門用語は不要です。
3. Codexがつくった3案を見て、「Bを採用」「Aの文字とCの背景」などと返します。
4. 採用案のファイルと、デザインの理由・変更方法を受け取ります。

### 最初の入力例
- サイト・ゲームの内容：夜の町を歩いて手紙を集める短いブラウザゲーム
- 誰に使ってほしいか：静かな物語や探索ゲームが好きな人
- 最初にしてほしい行動：ゲームを始める
- 欲しい雰囲気・避けたい印象：少し寂しいけれど温かい。派手なSFやホラーは避けたい
- 参考URL：なし。実在するサイトから提案してほしい
- 使える画像・ロゴ・既存サイト：まだなし
- 作業場所・保存先：現在のプロジェクト内に専用フォルダを提案してほしい

上記は入力例で、既存の実在作品や完成済みのデザインを示すものではありません。

### 続きの依頼例
> Bを採用。スマホでも見出しを読みやすくして、ボタンの動きは控えめに。採用案のファイルとデザインの説明を仕上げて。

> Aの文字の雰囲気が好き。背景はC寄りにしたい。組み合わせたときに合わない点があれば直して、理由も教えて。

> まだしっくりこない。特に中央に全部並んでいるところが普通すぎる。おすすめの案を1つ、構図から見直して。

## 準備と費用
このプロンプトの利用に追加プラグイン、APIキー、有料API、ソフトの追加インストールは必要ありません。文章ファイルであり、それ自体がAIやブラウザ機能を追加するものではありません。実行には通常のCodex利用枠を使います。無制限の無料実行や、契約枠の残量を保証するものではありません。

参考サイトの調査、ブラウザ検証、画像生成は、そのタスクで利用できる既存ツールに依存します。使えない機能は未実施と報告し、画像生成を必須にせず制作を続けるよう指定しています。別PCで不足があっても勝手にインストールしません。
画像生成は必要な場合だけ、現在の契約枠内で使えることを確認して利用します。GitHub操作は接続と、そのタスクでの許可が必要です。

## 保存と公開
このフォルダは再利用する指示文の正本です。Webアプリではないため、独自のGitHub Pagesページは作成しません。既存サイトとPages設定は変更しません。実際につくるヒーロー案の公開は、それぞれの制作タスクで指定できます。
