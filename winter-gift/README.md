# 冬の謎解き：ヒーローエリア5案

1月9日、学校で中学生と保護者が参加する謎解き企画のデザイン比較です。サンタのプレゼントが学校に残っている理由と届け先を探す、冬のミステリーを題材にしています。

## 開く
- 比較ページ： https://gamigamiigami.github.io/Codex/winter-gift/
- A〜E：a.html / b.html / c.html / d.html / e.html
- ローカルではindex.htmlをブラウザで開けます。ビルド・追加インストール・APIキーは不要です。

## 範囲
5案のヒーローと比較画面、開始ボタンの遷移先である短い導入文を実装しています。謎解き本編、申込機能、回答入力、参加者情報の収集はありません。正式タイトル・開催年・時刻・会場詳細・採用案は未確定です。

## ファイルと変更方法
- index.html：5案の比較、参考URL、おすすめ。
- a.html〜e.html：各ヒーロー。h1がタイトル、.hookが短いコピー、.descriptionが説明です。
- style.css：共通設定と.concept-a〜.concept-eの見た目。760px以下と360px以下で組み替えます。
- app.js：開始リンクから導入文へフォーカスを渡す補助。JavaScriptがなくても通常のアンカーとして使えます。
- assets/：この企画向けに制作したオリジナルSVG。外部の画像・ロゴは含みません。
- DESIGN.md：設計意図、参考の観察と限界。

## 公開と引き継ぎ
リポジトリ直下のwinter-gift/が正本です。Pagesは既存のおみくじのルートURLを維持し、kotoba-omikuji/とwinter-gift/の両方を同じ成果物に含めます。公開結果はPRとActions実行結果で確認できます。
次の作業は利用者による採用案の選択。選択後、タイトルやストーリーを確定し、その案に必要なファイルを独立させて納品します。現段階で勝手に採用していません。
